# Código de conduta

Queremos um espaço respeitoso para quem usa e contribui com o projeto, de qualquer nível de experiência.

**Esperado:** tratar as pessoas com respeito, criticar o código e as ideias (não quem as escreveu), aceitar feedback
com boa-fé e assumir erros com transparência.

**Não toleramos:** assédio, ataques pessoais, discriminação, exposição de dados pessoais de terceiros e spam.

**Aplicação:** os mantenedores podem editar ou remover comentários, issues e PRs, e restringir a participação de quem
violar estas regras. Para reportar um problema, use o recurso "Report" do GitHub ou contate os mantenedores em
particular, como descrito em `SECURITY.md`.

Este texto segue o espírito do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
